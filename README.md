# Shopify Theme – [Stratriv Powerd by dawn]

## 🛠️ Development Overview

This theme was built with a focus on performance, modularity, and clean UI/UX. My approach to developing this Shopify theme includes:

- **Component-Based Structure:** I structured the theme using Shopify's Dawn theme principles as a base, focusing on Liquid templates and modular CSS/JS.
- **Custom Features:** Implemented advanced cart functionality on product page [ Limited Edition Badge, Care Instructions, Size Chart Popup, lazy load, advance metafield].
- **Mobile-First Design:** Ensured responsive behavior across all devices.
- **Code Quality:** Kept the codebase clean and readable with reusable snippets and partials for ease of maintenance.
